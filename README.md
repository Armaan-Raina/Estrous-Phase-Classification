# Application of machine learning models to identify differences in neural electrophysiological properties across estrous cycle phases

## Background
Using whole-cell patch clamped cell recordings from female rat medium spiny neurons across four assessed estrous phases and three recording techniques (action potential bursts, passive membrane recordings, and miniature excitatory postsynaptic currents), seven machine learning models (MLMs) were trained to classify estrous phase based on biologically relevant features extracted from each recording type. The differences in model performance across the feature sets serves as a proxy for the influence of hormones on the specific aspect of neuronal function captured by the given recording type.
